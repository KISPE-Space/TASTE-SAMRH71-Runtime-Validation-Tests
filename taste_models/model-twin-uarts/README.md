# Misc Model

## Tests Implemented
- **TestTwinUarts**: Validates that two full-deplex UARTs can be implemented in a single TASTE model

## Requirements covered
- `MBEP-RT-IF-50` : TASTE Runtime shall support at least two UART interfaces to be configured and used separately.
- `MBEP-RT-OPER-20` : It shall be possible to execute an application built using the TASTE Runtime on the hardware target using an additional BSW.
