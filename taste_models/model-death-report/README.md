# Death-report Model

## Tests Implemented
- **TestDeathReport**: Validates that the TASTE runtime produces a death report on a UsageFault and that the death report can be obtained by a model

## Requirements covered
- `MBEP-RT-FUN-320` : TASTE Runtime shall produce a Death Report upon encountering a critical fault.
- `MBEP-RT-FUN-331` : TASTE Runtime shall report the encountered fault (Death Report).
