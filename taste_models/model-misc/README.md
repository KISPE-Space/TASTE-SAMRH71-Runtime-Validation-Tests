# Misc Model

## Tests Implemented
- **TestSdlTimer**: Validates SDL timers built with OpenGeode and generating C code work as expected
- **TestTime**: Validates that elpased time can be obtained from the TASTE runtime and that time values are reasonable

## Requirements covered
- `MBEP-RT-FUN-200` : TASTE Runtime shall support timers used in SDL-based TASTE Functions.
- `MBEP-RT-FUN-430` : TASTE Runtime shall support TASTE Functions implemented in SDL.
- `MBEP-RT-FUN-440` : TASTE Runtime shall support C code generated by OpenGEODE.
- `MBEP-RT-FUN-370` : TASTE Runtime shall provide the capability to query elapsed time.
