## Tests Implemented
- **TestMaxMatrix**: Validates 1:10, 10:10 and 10:1 interconnects between Required and Provided Protected interfaces

## Requirements covered
- `MBEP-RT-FUN-211` : TASTE Runtime shall support 1 to N intra-partition communication for values of N in the range of <1:10>.
- `MBEP-RT-FUN-221` : TASTE Runtime shall support N to 1 intra-partition communication  for values of N in the range of <1:10>.
- `MBEP-RT-FUN-231` : TASTE Runtime shall support N to M intra-partition communication  for values of N and M in the range of <1:10>.
