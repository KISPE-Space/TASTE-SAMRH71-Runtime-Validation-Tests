# Longer-Log Model

## Tests Implemented
- **TestLongerLog**: Validates that the length of the activation log can be configured and the resulting log entry count is greater than the default length

## Requirements covered
- `MBEP-RT-RES-680` : It shall be possible to configure the size of the activation log.
- `MBEP-RT-RES-310` : TASTE Runtime shall support user provided linker scripts.
